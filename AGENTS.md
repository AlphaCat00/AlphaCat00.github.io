# Website Editing Instructions

- Host every publication PDF in `assets/pdf/`.
- In `_bibliography/papers.bib`, set each publication's `pdf` field to its local filename, such as `memchannel-nsdi26.pdf`.
- Always point publication PDF buttons to these website-hosted copies. Publisher pages and DOI links may remain as separate reference links.
- When adding a publication, include its PDF and verify that the generated PDF link resolves to the local file.
